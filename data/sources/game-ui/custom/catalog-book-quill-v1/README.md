# 도감용 책과 깃펜 시안

- `icon.png`: 79×69 RGBA PNG. 두루마리+깃펜 원본과 같은 캔버스 크기이며 투명 배경이다.
- `master.png`: 내장 image_gen으로 생성한 1342×1172 RGBA 원본. `icon.png`는 비율을 유지해 축소하고 투명 여백으로 크기를 맞췄다.
- 게임에서 추출한 원본이 아닌 사용자 승인 AI 재구성 이미지다. 현재 배포 이미지와 원본 대응은 `../../menu-icons.json`을 따른다.
- 책 참고: `../../game-icons/sprite_0379_444_1414_36x36.png`.
- 깃펜·화풍 참고: `../../game-icons/sprite_0793_241_1979_79x69.png`.
- 사용자가 제공한 마인크래프트 이미지는 책과 깃펜이라는 구성만 참고했다.
- 생성 지시는 `prompt.txt`에 보존한다.

검증: sharp로 최종 PNG의 79×69 크기·RGBA와 완전 투명 픽셀/불투명 픽셀 존재를 확인하고 실제 크기를 시각 확인했다.
