## S5 회귀 사례

`node tools/test-dual-sword-s5.mjs`로 다음을 확인했다.

- 쌍검 장비·Lv.10에서 21개 전체 사용 가능, Lv.0에서 전체 사용 불가
- 트윈 슬래쉬 Lv.10 계수 2.5·상수 200, 비쌍검에서 사용 불가
- 에어 슬라이드 토네이도 3타, 루나 디재스터 후속 5타, 트윈 버스터 블레이드 2타 확정 크리티컬
- 돌아 들어가기 MP 단계식(Lv.1 400 / Lv.7 200)과 다음 스킬 1회 확정 크리티컬
- 세이버 오라의 고정 최대 스택 없음과 아크 세이버 Lv.10 CRIT +100

## 계산기 범위 밖 상태

- 세이버 오라·아크 세이버의 시간 경과, HP 지속 소모, HP 5% 종료, 종료 후 회복/쿨다운
- 패링·스텝 리액터 등의 피격 시 반격 또는 회피 성공 시 자동 발동
- 에어 슬라이서·스톰 리퍼의 위치, 거리, 통상 공격을 요구하는 부가 타격
- 아크 세이버의 세이버 오라 스택 소비와 피해 기반 MP 회복의 시간/피해 상태

위 항목은 대미지 계산 결과를 자동으로 바꾸지 않으며, 원문 규칙은 데이터 메타정보로 보존한다.
