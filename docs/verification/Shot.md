## 원문과의 실제 불일치·누락 (검증 시점)

1. **크로스 파이어 (Shot:4)**
   - 원문의 최대 차지는 Lv.1~3: 2, Lv.4~6: 3, Lv.7~9: 4, Lv.10: 5다.
   - 현재 입력값은 모든 레벨에서 1~5를 선택할 수 있어 저레벨에서 불가능한 차지를 선택할 수 있다.
   - 충전 MP 400/발사 MP 0, 첫 사용의 충전 상태 전이, 피격 시 충전 중지, 차지별 충전 시간은 현재 정의에 없다.
   - 자동활의 서브 탄 물리 관통 `기본 DEX / 10%`가 현재 정의에 없다.

2. **퀵 로더 (Shot:9)**
   - 현재 스택 수와 지속시간은 맞지만, 시전 시 하이드 어택 획득 규칙이 없다.
   - 크로스 파이어·페니트레이터 발사 시 최대 차지가 아니면 스택 1개를 써서 차지를 올리는 규칙이 없다.
   - 지속 중 재사용 시 스택/지속시간을 갱신하지 않고, 다음 스킬 행동 속도·MP 반환 효과를 주는 규칙이 없다.

3. **롱 레인지 (Shot:17)**
   - 원문은 공격이 실제로 원거리 판정인지가 아니라, **스킬의 시전 가능 사거리**가 8m 이상인지를 적용 조건으로 한다.
   - 현재 `longRange` 플래그는 이 조건을 충분히 표현하지 못한다. 스킬 메타데이터에 `castRange` 또는 별도 적용 플래그가 필요하다.

4. **파라볼라 카논 (Shot:14)**
   - 현재 원문 캐시에서 해당 정확한 이름을 찾지 못했다.
   - 원문이 구버전이거나 카탈로그 명칭이 바뀐 경우일 수 있으므로, 데이터화를 시작하기 전에 원문상 대응 스킬을 확정해야 한다.

5. **미등록 전투 자원형 상태**
   - 트윈 스톰(최대 99), 엘레멘트 리치(회복 배리어 최대 99), 무사 궁술(최대 10), 헌팅 • 원(최대 25), 페니트레이터(충전 최대 5)는 원문상 스택/충전 규칙이 있으나 현재 상세 정의가 없다.
