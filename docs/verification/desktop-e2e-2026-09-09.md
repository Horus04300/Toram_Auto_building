# 데스크톱 통합 E2E — 2026-09-09

## 실행 환경과 범위

현재 수정 소스를 `npm run desktop:build:exe`로 빌드한 Tauri 0.6.4 release 실행 파일을 사용했다. 웹 mock이 아닌 WebView2 → Tauri IPC → Rust 서비스/파일시스템 경로다. 설치 프로그램으로 설치한 앱은 아니다.

`tools/audit-desktop-e2e.mjs`는 실행마다 `src-tauri/target/desktop-e2e/<timestamp>/`를 만들고 자식 프로세스의 LOCALAPPDATA와 WEBVIEW2_USER_DATA_FOLDER를 격리한다. 사용자의 저장 파일·기존 브라우저 프로필을 테스트 대상으로 사용하지 않는다. 9224 포트가 이미 사용 중이면 기존 앱에 붙지 않고 중단한다. 테스트가 만든 프로세스만 정상 창 닫기로 종료하며 최종 실행은 두 번 모두 종료 코드 0이었다.

샌드박스 내 실행은 CDP 연결이 끊겼다. 자동 승인된 격리 프로세스 실행을 샌드박스 밖에서 수행하여 해결했다. 초기 실패를 제품 결함이나 통과로 집계하지 않았다.

## 관찰 및 남은 Gate

유효 추천을 찾기 전에 pause하면 최적해 대비 보장 오차가 `2313800000000000.00%`처럼 매우 큰 값으로 표시된다. 재개와 취소는 동작했지만, feasible 하한이 없는 상태의 사용자 안내는 별도로 점검할 필요가 있다. 이 값만으로 탐색 정확성 오류를 확정하지 않았다.

공개 Latest manifest는 HTTP 200, version 0.6.4, pub_date 2026-09-08T14:32:10.285Z였다. 현재 실행 앱과 같아서 새 버전 다운로드·승인·서명 검증·설치·재실행 경로는 진입하지 않았다. handoff의 공개 전 기록을 현재 배포 상태로 간주하면 안 된다.

다음은 **미실행**이다: NSIS 신규 설치·제거, 설치/제거 시 사용자 데이터 보존, 실제 vN→vN+1 업그레이드, 설치 중 오류/변조 업데이트/다운로드 중 새 계산의 Native E2E, 30초 slice 자동 연결, 실제 설치본의 장시간 계산. 이번 요청으로 릴리스 버전을 바꾸거나 새 공개 릴리스를 만들지는 않았다. 이 검사들을 포함한 전체 데스크톱 E2E 완료로 판정하지 않는다.
