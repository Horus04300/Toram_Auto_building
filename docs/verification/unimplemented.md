# 후속 작업·사용자 보류 범위

- 갱신: 2026-09-05. 완료 기능 설명·과거 단계 수·오래된 벤치마크를 제거했다.
- 역할: 남은 결정과 전투 이벤트 의존 항목의 탐색 목록. 구현 완료율이나 새 구현 승인 목록이 아니다.
- 현재 상태는 `docs/handoff/current-development-handoff.md`, 트리별 출처/범위는 `docs/verification/`의 해당 트리 문서와 실제 코드·회귀를 확인한다.
- S1 출처 연결, S2~S5 계산 검증, 실제 전투 상태 자동 전이는 서로 다른 완료 기준이다. 트리 문서의 과거 partial/단계 수만으로 현재 계산 누락을 단정하지 않는다.

## 1. 이미 연결된 것을 다시 구현하지 않기

충전·집념과 심안의 절대 명중/위치당 명중, Blade의 모델 범위 S4/S5 회귀, Native deadline/progress/pause/resume은 후속 구현 목록에서 제외한다. 2026-09-05 `tools/test-combo-tags.mjs`, `tools/test-blade-s4-s5.mjs`, `tools/test-d4-native-client.mjs`, `tools/test-d4-native-resume-ui-n5.mjs`가 통과했다. 실제 UI E2E 또는 모든 전투 상태 완료를 뜻하지 않는다.

이 항목에 새 오류가 있으면 아래 보류 목록을 활성화하는 대신 구체 입력으로 회귀를 추가한다.

## 2. 사용자가 별도 결정해야 하는 범위

| 항목 | 남은 결정/근거 | 경계 |
| --- | --- | --- |
| 콤보 길이·포인트·레벨 | 현재 임시 8칸 대신 원문 근거가 있는 포인트 모델을 사용할지 | 최대치 추정 금지. 경험치/레벨업도 별도 범위 |
| 심안의 저항 시 중단 | 대상 저항 시간의 자동 전이 | 명중 효과와 구분; 전투 상태 엔진 보류 |
| 무적·강인 | 모션/피격/받는 피해 자동 처리 | 피격 시뮬레이션 보류 |
| 흡혈 | 회복 표시와 시간 경과 후 HP 소모/피해 증가 전환 | 직접 표시와 시간 엔진을 분리해 결정 |
| 반사 | 미피격 분기를 수동 조건으로 제공할지 | 피격/통상/관성 자동 사건은 보류 |
| 현재 HP 기반 사용 가능성 | 집념·HP 소모 스킬의 실제 생존/사용 판정 | 직접 비용식과 실시간 HP 상태를 구분 |
| D2 중독 | 계산된 1회 피해의 화면 배치 | 사용자 보류. 지속시간/틱/부여 사건은 별도 |
| 자동 장비 옵션 부여 | 검증된 상한·잠재력 비용 카탈로그와 사용자 범위 선택 | `docs/architecture/equipment-option-assignment-spec.md` |
| 고정/완성 장비 후보 확장 | 현재 크리스타 추천에 어떤 장비 교체 변수를 추가할지 | 후보·잠금·계보·Utility의 정확성 Gate 필요 |
| 탱커 최적화 | 목적함수·제약과 사용자 흐름 | 옵션 데이터 보존과 자동 추천 지원은 별개 |

강타 말단/MP 취소 등 추가 경계 회귀는 관련 코드 수정 시 보강한다. 테스트를 더 만들 수 있다는 이유만으로 현재 구현 전체를 미완료로 표시하지 않는다.

## 4. D4 후속 작업을 여는 기준

현재 크리스타 compiler·평가기·탐색·Worker/Native·잠금·Utility·결과 UI를 다시 구현 목록에 넣지 않는다. 성능 변경은 `docs/architecture/d4-exact-optimization-plan.md`, 실행 제어는 `docs/architecture/d4-native-runtime-correction-plan.md`의 Gate를 따른다.

- 과거 425개 fixture의 단발 시간/gap을 현재 성능으로 보고하지 않는다.
- 옵션 자동 부여의 로그 한계효용/잠재력 탐색은 현재 수동 완성 옵션과 구분한다.
- 조건부 main/sub/armor는 구조를 확정한 뒤 사전 물질화한다. 범용 동적 조건 엔진 확장은 먼저 제품 범위를 결정한다.
- 보류 항목은 사용자 선택 후 원문→코드→관련 회귀 순으로 범위를 확정한다.

새 후속 항목은 대상·재현/원문·현재 지원과의 차이·보류 여부·검증 명령만 기록한다. 완료되면 여기서 제거하고 현재 상태의 해당 항목을 갱신한다. 12 KiB 이하로 유지한다.
