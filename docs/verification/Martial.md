## 검증으로 확인된 보완점

1. 아수라 오라는 일반적인 지속시간형 버프가 아니라 ON/OFF 양방향 전투 자원형 상태다. 따라서 OFF 후에도 스택 조절 UI를 유지하고, OFF 상태 효과도 별도로 계산 대상으로 연결했다.
2. UI 상한은 원문의 사망 경계인 40으로 두되, 효과의 경계는 20스택 초과부터 별도로 기록했다. 두 숫자를 하나의 보정 상한으로 취급하지 않는다.
3. ON 상태의 권갑 보정은 기본 CRIT `2.5 × 레벨`의 3배와 전역 상수 `10 × 레벨`의 2배이므로, 권갑 Lv.10 기준 각각 CRIT +75와 상수 +200으로 데이터화했다.
4. 비권갑 선택 시 아수라 오라가 계산 대상이 되지 않도록 무기 제한을 엔진 조건으로 연결했다.

## 이번 확인 사례

- 권갑, 아수라 오라 Lv.10, ON: CRIT +75가 계산 프로필에 나타나는지 확인.
- 한손검, 아수라 오라 Lv.10, ON: 스킬이 사용 불가로 판정되는지 확인.
- 스택 제어: 최대 40, OFF 중 스택 보존·표시·효과 적용 플래그가 모두 존재하는지 확인.

위 사례는 현재 엔진이 계산할 수 있는 무기 제한·정적 효과·UI 상태 규칙만 검증한다. MP 소비와 통상공격으로 변하는 실제 전투 경과는 S5 사례로 아직 승격하지 않았다.
