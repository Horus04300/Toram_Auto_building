## S5 회귀 사례

`node tools/test-sprite-s5.mjs`로 다음을 확인했다.

- 마도구·Lv.10에서 17개 전체 사용 가능, Lv.0에서 전체 사용 불가
- 클라인 힐 Lv.10 회복량 1100, 리저렉션 Lv.10 영창 5초
- 오토 디바이스 마법 통상 특수 공격과 아스트랄 랜스 Lv.10 계수 7.5
- 매직 불칸 최초 5타·2회 유지 10타, Lv.10 유지 계수 2.6
- 이그니션 계수 상한 12, 알데드락 Lv.10 계수 9
- 팍티스알름 문 슬래시 분기 2타 확정 크리티컬, 슬래시 리퍼 5자루 발사
- 인핸스 Lv.10 활성 시 공격 배율 +10%
- 지팡이에서는 메인 마도구 전용 스킬 사용 불가

## 계산기 범위 밖 상태

- 오토 디바이스 자동 통상과 9m 이상 간격/AMPR 변화
- 러쉬 에이드, 스프라이트 실드, 카운터포스의 피격·파티원·HP 자동 판정
- 아스트랄 랜스/슬래시 리퍼의 MP 사용·상태이상·시간에 따른 자동 스택 변화
- 리저렉션 대상의 사망/응급처치 가능 여부, 인핸스 대상 선정, 카타라보모스 대상 HP 기반 도트
- 레벤그란츠 MP 축적, 생명 폭파 피해/대상 수, 플레지와 같은 파티·영역 상호작용

원문 수식과 발동 조건은 데이터에 보존하며, 위 사건은 현재 계산 결과를 자동으로 변화시키지 않는다.
