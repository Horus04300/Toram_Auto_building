## 반영 내용

패밀리어, 라이트닝, 블리자드, 메테오 스트라이크, 임페리얼 레이, 마나 크리스탈, 스톤 스킨, 하이 패밀리어, 크리스탈 레이저, 오버 리미트, 시프트를 원문 수치와 조건으로 연결했다. 위저드 공격에는 원문상 MATK 혼합 규칙을 플래그로 보존했다.

라이트닝·블리자드·메테오는 하이 패밀리어 레벨 입력을, 임페리얼 레이는 표식 발동 입력을, 크리스탈 레이저는 사역마/마나 크리스탈 존재 입력을 사용한다. 패밀리어의 MAXMP/MATK와 캐스트 마스터리의 CSPD%는 빌드 효과로 기록했다.

## S5 회귀 사례

`node tools/test-wizard-s5.mjs`로 다음을 확인했다.

- 지팡이 또는 필요한 메인 마도구 조건에서 15개 전체 사용 가능, Lv.0에서 전체 사용 불가
- 패밀리어 Lv.10 최대 MP +200, 캐릭터 Lv.300 기준 MATK +75
- 라이트닝 Lv.10·하이 패밀리어 Lv.10 계수 11.5·MP 0
- 블리자드 Lv.10 6타·각 계수 2.25, 메테오 스트라이크 3타·각 계수 22.5
- 임페리얼 레이 Lv.10 첫타 계수 10/상수 400, 표식 후속타 계수 20
- 마나 크리스탈 MP 0, 크리스탈 레이저 Lv.10 계수 10·상수 200 및 결정 부재 시 피해 없음
- 지팡이/마도구 장비 조건 차단

## 계산기 범위 밖 상태

- 사역마 소환/도주/피격 영창 취소, 하이 패밀리어 자동 시전
- 마나 크리스탈 공동 영창·설치·접촉 회복·소멸과 크리스탈 레이저 실제 소비
- 임페리얼 레이 대상 표식·속성 약점·쇠약, 고양이의 분실물 결정 생성
- 스톤 스킨 배리어 피격 처리, 오버 리미트 HP 소모/침묵 종료, 시프트 MP 소모·무적·회피 이력
